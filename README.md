# Spore revival figure and analysis workflow

Reproducible R workflow for the phenotype, transcriptome and secondary-spore analyses used to generate manuscript Figures 2–7 and Supplementary Figs. S1–S3.

> **Pre-release hold:** do not make this repository public until the authors approve the data release, repository title, citation metadata and software license.

## Scope

- Figure 2: fixed, author-approved microscopy montage plus reproducible germination-kinetics and model-implied-difference panels.
- Figure 3: stage-resolved germination kinetics.
- Figure 4: growth-curve modelling and parameter-space analysis.
- Figure 5: transcriptome variance decomposition and KEGG pathway scores; the score formula and DEG threshold are defined in the manuscript legend rather than repeated inside panel b.
- Figure 6: functional-category expression and phenotype associations.
- Figure 7: secondary-spore baseline growth, antimicrobial response and transcriptome–phenotype correlations.
- Supplementary Figs. S1–S3: secondary-spore DDAC/NaHCO3 responses, all-sample RNA-seq PCA and replicate-level logistic fits, with figure-specific source-data exports.
- Supplementary Tables S1–S3: complete differential-expression results, functional-category membership and replicate-level logistic-model fit parameters generated by the workflow.
- Inoculum-turbidity quality control: overall 0 h OD600 and the coefficient of variation among the eight treatment-group means.
- RNA-seq count-level quality control is exported as an internal audit file rather than a numbered Supplementary Table.
- Statistical audit scripts for Figures 3, 4, 5 and 7.

Figure 1 is not generated here because its experimental-design artwork has no editable source layout. Figure 2 is included with an explicit boundary: the 32 raw microscopy fields are currently held separately by the originating laboratory, so panel a is preserved from the author-approved flattened manuscript figure as a fixed raster input. Panels b and c, their source-data tables, and the final Figure 2 assembly are regenerated by R.

## Quick start

Run commands from the repository root.

```bash
Rscript -e 'if (!requireNamespace("renv", quietly = TRUE)) install.packages("renv", repos = "https://cloud.r-project.org"); renv::restore()'
Rscript R/preflight.R
Rscript R/render_all.R
```

If `renv` is not available, install the current CRAN versions as a fallback:

```bash
Rscript requirements.R
Rscript R/preflight.R
Rscript R/render_all.R
```

All generated PDF, SVG, TIFF, PNG and source-data files are written to `results/`. The render script also records `sessionInfo.txt` and runs `R/validate_manuscript_claims.R`, which stops the workflow if key numerical claims or Supplementary Table dimensions no longer match the manuscript.

## Reproducibility conventions

- The repository root is detected from the working directory or `PROJECT_ROOT`.
- `renv.lock` records the validated R 4.5.2 package environment; `requirements.R` remains an unpinned fallback installer.
- Random seeds are set inside the relevant scripts.
- Reader-facing factors are reported consistently as X-ray dose and gravity condition (1 g versus SMG). RCCS identifies the method used to generate SMG.
- `R/inoculum_OD600_uniformity_qc.R` reproduces the reported mean OD600 and the coefficient of variation among the eight treatment-group means; it also exports the individual-value coefficient of variation for audit transparency.
- Figure 2 panel a is not raw-image reproducible; its fixed-raster provenance and crop are disclosed in the script and data manifest.
- Figure 7 treats `control_1` and `control_2` as two measurement sets belonging to one combined baseline dataset, not as six independent biological replicates.
- Figure 7 antimicrobial AUCs are calculated at the biological-replicate level (`n = 3`).
- Each estimable Figure 7 correlation uses three dose-level group observations; no significance stars are displayed.
- Figure 3 and Figure 4 symbols use Holm-adjusted p values for the four planned 1 g-SMG comparisons within each endpoint; effect estimates and 95% confidence intervals are exported with the source data.
- Figure 5 PERMANOVA is reproduced from Hellinger-transformed count matrices, with time-specific PERMDISP diagnostics exported separately.
- Supplementary Table S1 is rebuilt from all 14 processed DEG contrasts with explicit timepoint, gravity-condition, dose and contrast metadata.
- Supplementary Table S2 is rebuilt from the complete unique gene membership used by the functional-category scoring rules; the displayed Figure 6a subset does not define category membership.
- `R/validate_manuscript_claims.R` verifies 46 prespecified numerical and structural claims spanning inoculum QC, Figs. 3–7, Supplementary Fig. S3 source data and Supplementary Tables S1–S3.
- Known statistical and feature-selection boundaries are documented in `docs/statistical_decisions.md`.
- The exact script-to-input mapping for every figure is documented in `docs/figure_input_manifest.md`.
